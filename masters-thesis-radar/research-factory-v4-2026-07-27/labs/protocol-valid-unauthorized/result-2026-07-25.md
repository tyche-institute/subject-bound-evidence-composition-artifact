## Differential

В первых 15 отрицательных случаях:

```text
protocol schema/signature  = VALID
native authorization A0    = VALID
native effect evidence E0  = VALID
composed seam C1           = DENY(first_rejecting_gate)
```

Последний отрицательный control:

```text
runtime state              = favourable
native authorization A0    = ABSENT
native effect evidence E0  = VALID
composed seam C1           = DENY(authorization.present)
```

Важно: независимый аудит обнаружил, что `first_bad_edge` в v0 лишь копирует
`case.edge.edge_id`, а expected object не содержит edge/index. Поэтому
`16/16` относится только к имени первого rejecting gate; claim о
минимальном bad edge в multi-hop path этим corpus не поддерживается.

Этот gap затем закрыт отдельным `delegation-paths.json` suite: 12/12 expected
tuples на paths длины 1/2/4, 9/9 first-invalid stages и 7/7 настоящих
delegation-edge ID/index. В multi-fault control найден именно ранний
`edge-1`; более поздние defect stages остались `NOT_EVALUATED`. Независимая
relational SQL implementation затем совпала с Python evaluator и expected
tuples 12/12. Expected labels всё ещё происходят из общей design process.

## Hybrid adapter к записанному A2A evidence

`adapters/boundary_seal_adapter.py` читает не выдуманный envelope, а
сохранённый результат существующего A2A boundary-seal:

```text
a2a-boundary-seal/results/extension-enabled/send-message.json
```

Адаптер декодирует реальный capsule, заново вычисляет capsule/effect hashes
и проверяет binding к task, context, originating message и terminal effect.
Затем он соединяет этот native evidence с экспериментальным mandate overlay.

Получено 7/7 expected verdicts:

- один exact authorized control — `ALLOW`;
- пять случаев с native-valid A2A evidence и native-valid authority object,
  но несовместимым task/context/origin/effect/freshness — `DENY` с точной
  локализацией;
- один случай good evidence при отсутствующем mandate — `DENY`.

Checksums находятся в `results-boundary-adapter/SHA256SUMS`. Это переводит
evidence class из полностью synthetic в **hybrid recorded protocol evidence**,
но не доказывает A2A-conformance экспериментальных mandate fields.

## Что этот result поддерживает

Synthetic v0 показывает существование и executable detectability класса
ошибок, в котором native proof/evidence validation недостаточна без
cross-layer semantic composition.

## Что result пока не поддерживает

- claim уникальности или первенства benchmark;
- A2A/MCP conformance experimental authority fields;
- реальный WAVE/JEDI/MachineMandate adapter;
- signature/issuer/revocation infrastructure;
- independent first-bad-edge oracle;
- multi-hop path длиннее четырёх edges;
- generalization на реальные agent systems;
- comparative superiority над existing benchmarks.

## Prior-art gate и pivot

Отдельный primary-source overlap review убил два широких тезиса:

- это не первый benchmark несанкционированных tool actions;
- role-isolated teamwork не является самостоятельным novelty claim.

Сохраняется более узкий объект:

> typed revocable delegation chain + role-isolated execution + native-valid
> tool/evidence artifacts + deterministic first authority-invalid edge.

Рабочее название: **Who Authorized This Edge? Benchmarking Protocol-Valid
but Authority-Invalid Actions in Role-Isolated Agent Teams**.
