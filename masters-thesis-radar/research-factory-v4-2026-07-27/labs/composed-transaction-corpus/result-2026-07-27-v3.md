## What this rebuild is for

The v2 composed verifier ALLOWED the article's own section-1
counterexample: a correctly Ed25519-signed evidence object with effect
`ledger.write` on resource `invoice-999` and a fresh nonce, under the
unmodified `PSR_correct_good` policy whose `required_effect` is
`ledger.read`, evaluated against an ALLOW delegation path whose terminal
grant carries only `ledger.read` on `invoice-123`, returned
`policy PASS / evidence PASS / state PASS / authority ALLOW /
measurement PASS`, verdict **ALLOW**, first rejecting gate `verified`.

The composition thesis was asserted, not implemented. v3 implements it: an
explicit binding stage in `composition_rule.py`, the two subject records
`canonical_action` and `observed_effect` as real transaction fields, and a
`cross_layer_binding` family of transactions in which every artefact
verifier passes locally and the join refuses.

## The four-of-five identity

The v2 identity — the four-of-five majority's false allows are exactly the
single-fault denies — **no longer holds**, and its failure is the point of
the rebuild. Reported both ways in `summary.json`:

| | v2 | v3 |
| --- | ---: | ---: |
| four-of-five false allows | 23 | 31 |
| single-fault denies | 23 | 23 |
| cross-layer denials | 0 (unrepresentable) | 8 |
| `four_of_five == single_fault` | holds | **does not hold** |
| `four_of_five == single_fault ∪ cross_layer` | (trivially) holds | **holds** (set equality on ids) |

A four-of-five majority allows a transaction iff at most one of the five
artefact verifiers fails. Once denials with *zero* failing verifiers exist,
its false allows are the single-fault denies **union** the cross-layer
denials. Single-fault layer distribution is unchanged: authority 14,
policy 3, measurement 3, evidence 2, state 1.

## Supported claim

Within this frozen synthetic/hybrid corpus, individually valid artifacts
were insufficient for a non-compensable delegated decision — including on 8
transactions where **every one of the five component verifiers returned a
pass** and the denial was produced by the join, among them the article's
own section-1 counterexample. Each of those 8 is paired with an all-valid
lookalike control that was allowed, so the refusals are not universal
refusal. Compensating and presence-only ablations created false allows on
every family; the four-of-five majority cannot represent any of the 8
cross-layer denials at all.

## Claim ceiling

The binding stage is a deterministic string-agreement and
interval-containment condition over subject fields read out of
corpus-supplied artefacts. It verifies no signature, takes no measurement
and is not attestation of any runtime. `canonical_action` and
`observed_effect` are derived from corpus artefacts and re-checked, but
they are corpus-supplied strings throughout. The evidence and measurement
variants used by the binding family are owned by this laboratory and
disclosed as such in `corpus.json`; the sibling evaluators that appraise
them are unmodified. The result does not establish production prevalence,
superiority over named systems, external label independence, legal validity
or deployed interoperability. Expected labels are author-written;
composition-level agreement is analytic (B1). The SQL oracle re-derives the
binding outcome but consumes subject strings from the Python evaluator: it
is a second composition code path, not an independent source. The three
decision-relevant time constants in the artifact remain unrelated, so time
binding tests window containment and never equality — a limitation this
rebuild reports and does not repair.

## Article changes this rebuild requires

1. **Section 1 must delete** "A mismatch between the canonical action and
   the observed effect therefore surfaces as an authority or evidence
   failure." It is false: neither layer can see both sides. The mismatch
   surfaces only at the join.
2. **Section 1's decision rule** becomes
   `Allow(x) = B(x) ∧ P(x) ∧ E(x) ∧ S(x) ∧ A(x) ∧ M(x)`, where `B` is a
   well-formedness condition on the conjunction and ranges over the subject
   records rather than over a sixth artefact.
3. **Section 4's record format is now true** as written: `canonical_action`
   and `observed_effect` exist, and the binding stage reads them.
4. Every count that changed is listed above; the previously published
   "distinct non-empty failure subsets, v1: 14" was wrong and is 13.
